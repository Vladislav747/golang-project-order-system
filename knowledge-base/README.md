# Knowledge base (для агентов)

Локальная база знаний проекта. Агенты **сначала** читают сюда релевантные заметки, потом лезут в код/`PLAN.md`.

## Как пользоваться

- Пиши короткие markdown-заметки по теме (один файл — одна тема).
- Обновляй статус, когда фаза/решение меняется — не копируй весь `PLAN.md`.
- Не клади секреты (`.env`, ключи, пароли).
